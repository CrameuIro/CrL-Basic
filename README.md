# A batch tool prepared for LineageOS or LOS-based systems.

Connect the device to Windows and run CRL.bat, some of your system applications will be disabled and replaced with better alternatives:

1. Browser (org.lineageos.jelly) -> Via (mark.via)
2. Camera (org.lineageos.aperture) -> Camera (app.grapheneos.camera)
3. Music (org.lineageos.twelve) -> Booming Music (com.mardous.booming)

In addition, several other apps will be installed on your device:

1. F-Droid Basic (org.fdroid.basic)
2. InstallerX Revived (com.rosan.installer.x.revived)
3. Localsend (org.localsend.localsend_app)
4. MT Manager (bin.mt.plus)

The included app packages are all the latest versions.
